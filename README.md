## 👋 What is Cowork?

**Claude Cowork** (technically known as *Computer Use*) allows the AI to interact with a computer just like a human does: looking at the screen, moving the cursor, clicking buttons, and typing text.

## Best Prompts & Use Cases

> **⚠️ Note:** See full prompt texts and configurations at [AwesomeCowork.com](https://awesomecowork.com/prompts).

- **Desktop Cleaner Agent** - Automatically organizes your Downloads folder.
- **Invoice Processor** - Extracts data from PDF invoices and saves to Excel.
- **Web Scraper** - Navigates websites to collect data autonomously.
- **Bug Fixer** - Runs local tests and attempts to fix code errors.

## Tools & Environment

- **[Docker Desktop](https://www.docker.com/)** - Required for running the sandbox safely.
- **[E2B](https://e2b.dev/)** - Secure cloud sandboxing for AI agents.
- **[Model Context Protocol (MCP)](https://modelcontextprotocol.io/)** - The standard for connecting Claude to local data.
- **[Open Source Claude Cowork](https://opensourceclaudecowork.com)** - A handbook for the open-source route to Cowork-style agents: the active projects compared by what each one keeps, self-hosting steps, and which files hold the skills, permissions and memory.
